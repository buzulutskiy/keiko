# Что стояло в середине строки под названием — снято

Стояла в релизах 412–413, снята в 413+ по живому отзыву: «мне достаточно, что
я просто занимаюсь, а не то, как быстро это».

Строка была из трёх частей:

    7 дн. из 12 · 11 стр. в день · примерно к началу октября

Осталось возвращение и срок:

    7 дней с книгой · примерно к началу октября

Заодно ушёл и знаменатель. «7 из 12» — доля от календаря, а её нельзя
отыграть: пропустил неделю — она просела навсегда, потому что в прошлое не
вернёшься, и дальше падает, как ни занимайся. Счёт дней растёт с каждым
возвращением, в том числе после месяца тишины.

## Почему сняли

Скорость отвечает на «как быстро», а ценность в другом: что к книге
возвращаешься, пусть и понемногу. Три части читались как перебор, и лишней
оказалась именно та, что про темп. Доля («темп 58%») не вернулась туда же:
она уже есть в «7 из 12», и показывать одно и то же дважды — тот же перебор.

## Как вернуть

В `app.js` перед `FINISH_WORD` вставить:

```js
const UNIT_WORD = {
  page: ["стр.", "стр.", "стр."],
  lesson: ["урок", "урока", "уроков"],
  minute: ["мин.", "мин.", "мин."],
  bar: ["такт", "такта", "тактов"]
};

function paceSpeed(f) {
  const слова = UNIT_WORD[f.unit];
  /* Внутри пьеса считается проходами — так срок точнее: такт, набравший
     половину заходов, тоже сдвигает дату. Но «семь проходов в день» — число
     из внутренней кухни. Показываем то, что человек закрывает: такты. */
  const rate = f.rate / (f.perUnit || 1);
  if (!слова || !rate) return "";
  if (rate >= 1) {
    const n = Math.round(rate);
    return `${n} ${plural(n, ...слова)} в день`;
  }
  const n = Math.round(rate * 7);
  return n >= 1 ? `${n} ${plural(n, ...слова)} в неделю` : "";
}
```

В `paceForecast` перед `if (!left)` вернуть пересчёт проходов в такты и
добавить `perUnit` в оба `return`:

```js
const perUnit = unit === "bar" && piece().bars ? total / piece().bars : 1;
```

В `paceHTML` вставить третьей частью `subLine`: `часто < 1 ? IDLE_WORD() : paceSpeed(f)`.

Тесты на это лежали в `tools/test.js` рядом с «прогноз: …» — проверяли, что
скорость сходится с датой (`Math.ceil(f.left / f.rate) === paceWhen(f).days`),
что медленному материалу счёт идёт неделями и что пьеса меряется тактами,
а не проходами.

# Частота словами — тоже снята

Стояла один релиз (415). Между числом дней и сроком показывалось, как идёт в
последнее время: «почти каждый день», «через день», «пару раз в неделю»,
«раз в неделю». Снята по отзыву: «убери, не нужно это».

Осталось только прямое слово о простое — «не читаю», «не играю», «не рисую», —
и оно живёт в `paceIdle`.

## Как вернуть

Шкала и расчёт частоты:

```js
/* Как часто садишься. Считаем по тому же окну, что и срок. */
function paceOften(list) {
  const дни = [...new Set(list.map((e) => e.date))].sort();
  if (!дни.length) return 0;
  const i = Math.max(0, дни.length - RECENT);
  const прошло = Math.max(1, daysBetween(дни[i], todayStr()) + 1);
  return (дни.length - i) / прошло * 7;
}
const OFTEN_WORD = [
  [5,   "почти каждый день"],
  [3,   "через день"],
  [1.5, "пару раз в неделю"],
  [0.8, "раз в неделю"],
];
function paceOftenText(list) {
  const дни = [...new Set(list.map((e) => e.date))].sort();
  if (!дни.length) return "";
  if (daysBetween(дни[дни.length - 1], todayStr()) > 7) return IDLE_WORD();
  if (дни.length < 2) return "";   // из одного захода частота не следует
  const n = paceOften(list);
  return (OFTEN_WORD.find(([порог]) => n >= порог) || [0, IDLE_WORD()])[1];
}
```

В `paceHTML` и `paceDaysHTML` вместо `paceIdle(list)` подставить
`paceOftenText(list)`.
