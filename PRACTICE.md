# Как разучивается пьеса

Порядок, по которому «Практика» ведёт занятие. Это описание того, что уже работает
в приложении, а не план.

## Единицы

- **Такт** — минимальная единица работы.
- **Блок** — не длиннее четырёх тактов: 1–4, 5–8, 9–12 и так далее. Хвост пьесы
  может быть короче.
- **Заход** — один сыгранный такт (или блок целиком), отмеченный кнопкой.
- **Круг** — проход по всем тактам блока: 1, 2, 3, 4 — и снова с первого.

## Круги

Такты внутри блока идут по кругу, а не подряд до победы: сыграл первый —
отметил, второй — отметил, третий, четвёртый, и заново. Каждому такту нужно
набрать **десять заходов**. Приложение само выбирает, какой такт сейчас: тот, у
кого заходов меньше всех, при равенстве — самый левый. Отсюда и получается
ровный круг.

Возвращаться к одному и тому же месту через промежуток — единственный способ,
которым запоминают пальцы. Поэтому десять заходов не идут подряд: между ними
всегда остальные такты блока.

## Три отметки вместо одной

Кнопка не одна:

| Отметка | Цвет кружка | Что значит |
|---|---|---|
| Легко | мятный | пальцы сами |
| С усилием | золотой | вышло, но пришлось собраться |
| Сложно | фиолетовый | спотыкался |

Это не оценка себе. Во-первых, по цепочке кружков видно, где место тяжёлое, а
где уже сделано. Во-вторых, от отметки зависит сшивка блока. Красного в палитре
нет намеренно: «сложно» — это состояние места, а не провинность играющего.

Под тактами всегда стоит десять кружков — они и есть прогресс: заполняются
цветом того захода, каким он вышел.

## Сшивка блока

Когда все такты блока набрали по десять заходов, приложение предлагает сыграть
блок целиком. Дальше по результату:

- **сложно** — повторяем ещё раз, столько раз, сколько нужно;
- **с усилием** или **легко** — блок закрыт, начинается следующий.

Резкого «а теперь с первого по восьмой» не бывает: к блоку целиком приходишь,
сыграв каждый его такт по десять раз.

## Что считается прогрессом

- **Процент пьесы** — доля набранных заходов: все такты по десять плюс сшивка
  каждого блока (она весит как один такт). Начал с сорокового такта — процент
  честно покажет одну сороковую, а не «почти всё».
- **Прогноз «примерно к…»** — по тем же заходам: цель равна числу тактов,
  умноженному на десять, а темп берётся из последних занятий.
- **Отметка дня** ставится за время за инструментом, а не за закрытые заходы:
  сорок минут разбора — это занятие, даже если ни один такт не дошёл до конца.

## Запись рядом

Если у пьесы есть запись, плеер стоит на том же экране. В разборе может лежать
`marks` — такт → секунда, где он начинается; тогда плеер сам выделяет то место,
которое сейчас разучиваешь. Края после этого можно двигать руками, приложение
их не перебивает до следующего такта. Кнопка «↺ Сначала» переигрывает отрезок с
его начала.

Разметка заливается скриптом:

```bash
python3 tools/marks.py <id пьесы> разметка.txt
```

Формат строки — «Такт 7: 0:37.43 – 0:43.92». Берётся только начало такта: конец
это начало следующего, поэтому последняя строка нужна как граница.

## Что хранится

В данных профиля, `practice[<id пьесы>]`:

```json
{
  "reps":  { "7": [{ "lvl": 1, "d": "2026-08-24", "at": 1787594545865 }] },
  "final": { "1-4": [{ "lvl": 3, "d": "2026-08-24", "at": … }] },
  "session": 38,
  "at": 1787594546863
}
```

`lvl` — 1 легко, 2 с усилием, 3 сложно. При синхронизации по каждому такту
берётся тот список, где заходов больше: они дописываются только в конец, поэтому
длинный включает короткий.

Каждый заход, кроме отметки, уходит отрезком в запись дня — чтобы «сколько
сыграно» и «когда трогал этот такт» считались из истории занятий, а не из
разбора.
