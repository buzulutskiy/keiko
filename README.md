# Кэйко (稽古)

Трекер занятий, в котором **нет ни одного материала**. Приложение — только оболочка: книги, пьесы, курсы, награды, карточки знаний, обложки, мысли и профили лежат в личном **GitHub Gist** и подгружаются после подключения.

Название — от японского 稽古 (кэйко): регулярная практика, где важен не результат, а сам повторяющийся заход.

Статический PWA без бэкенда: `index.html` + `app.js` + `sw.js`.

## Как это работает

При первом запуске приложение просит **токен GitHub** (классический, scope `gist`).
Дальше оно само находит свои гисты по именам файлов и загружает два источника:

| Что | Где лежит | Что внутри |
|---|---|---|
| **Данные** | гист с `keiko-<профиль>.json` | материалы профиля, отметки занятий, мысли, полка, паузы, настройки |
| **Каталог** | гист с `keiko-catalog.json` | имена профилей, награды, карточки знаний, комментарии и разборы, обложки (по файлу на материал) |

Каталог кэшируется локально и сверяется условным запросом по метке — часто и дёшево;
обложки качаются лениво, только когда материал показан. Дальше приложение работает
офлайн: service worker держит оболочку, данные лежат в localStorage.

Подробное описание — в [HANDOVER.md](HANDOVER.md): гисты, синхронизация, модель данных,
треки, правила работы и список уже наступленных граблей.

## Формат каталога

```json
{
  "v": 1,
  "profiles": [{ "id": "…", "name": "…", "hint": "…" }],
  "materials": {
    "<id материала>": {
      "cover": true,
      "ach": [{ "id": "…", "icon": "🔑", "name": "…", "hint": "…", "secret": false,
                "when": [["page", ">=", 45]] }],
      "words": { "<id награды>": "текст, который показывается при получении" },
      "facts": [{ "t": "заголовок", "x": "текст", "more": ["куда копнуть"], "page": 45 }],
      "notes": [{ "ch": 1, "line": "1–10", "t": "…", "x": "…" }],
      "article": [{ "ch": 1, "h": "раздел" }, { "ch": 1, "p": "абзац" }]
    }
  }
}
```

Условия наград — данные, а не код. Метрика, оператор и значение: `[["pct", ">=", 100], ["days", ">=", 20]]` — все условия в списке объединяются по И. Операторы: `>=`, `>`, `<=`, `<`, `==`, `is` (для флагов), `has` (для наборов). Доступные метрики зависят от вида материала: `pct`, `page`, `days`, `streak`, `maxJump`, `bars`, `pctR`, `pctL`, `done`, `lessons`, `minutes`, `weekend`, `reread`, `comeback`.

Обложки — отдельные файлы `cover-<id>.txt` с data URI, чтобы ни один файл гиста не разрастался.

## Экраны

- **◉ Главная** — лента обложек, кольцо прогресса, прогноз «в таком темпе примерно к…», кнопка отметки. Фон перекрашивается под обложку активного материала: оттенок берётся из самой картинки.
- **▤ Прогресс** — неделя или месяц: кольцо цели, метрики, график, общий календарь.
- **✎ Мысли** — лента записей с обложкой материала, лайками, фильтром любимых и кубиком «одна наугад».
- **✧ Захотелось** — куда съездить, что прочитать, купить, сделать.
- **📚 Библиотека** (в настройках) — материалы в работе, полка прочитанного и карта знаний.
- **Мысль дня** — первый заход за день показывает одну из записей, без повторов внутри круга.

## Сохранность

- Данные всегда локальны, гист — копия. Слияние по времени правки, удаления помечаются флагом.
- Раз в неделю снимок всех данных уходит в отдельный гист-архив: файл на месяц, последние двенадцать.
- Резервная копия в файл и восстановление из него — в настройках.

## Локальный запуск

```bash
python3 serve.py 8473
```

## Релиз

Версию поднимать в трёх местах: `APP_VERSION` в `app.js`, `version.json`, `CACHE` в `sw.js`.
Дальше `git push origin HEAD:main` — GitHub Pages, и в приложении появится баннер обновления.

## Скрипты

```bash
python3 tools/material.py <id> <профиль>   # проверить материал перед словом «залито»
python3 tools/notes.py    <id> файл.txt    # комментарии к главам
python3 tools/article.py  <id> файл.txt …  # разборы для книжного клуба
```
