# Кэйко (稽古)

Трекер занятий, в котором **нет ни одного материала**. Приложение — только оболочка: книги, пьесы, курсы, награды, карточки знаний, обложки, мысли и профили лежат в личном **GitHub Gist** и подгружаются после подключения.

Название — от японского 稽古 (кэйко): регулярная практика, где важен не результат, а сам повторяющийся заход.

Статический PWA без бэкенда: `index.html` + `app.js` + `sw.js`.

## Как это работает

При первом запуске приложение просит **токен GitHub** (классический, scope `gist`) и, при желании, id гиста — если id не указать, гист найдётся сам по имени файла `prokachka.json`.

Дальше загружается два источника:

| Что | Где лежит | Что внутри |
|---|---|---|
| **Данные** | гист с `prokachka.json` | профили, материалы, отметки занятий, мысли, полка, паузы, настройки |
| **Каталог** | гист с `catalog.json` | имена профилей, награды, карточки знаний, обложки (по файлу на материал) |

Каталог кэшируется локально и сверяется не чаще раза в сутки, обложки качаются лениво — только когда материал показан. Дальше приложение работает офлайн: service worker держит оболочку, данные лежат в localStorage.

## Формат каталога

```json
{
  "v": 1,
  "profiles": [{ "id": "…", "name": "…", "hint": "…" }],
  "materials": {
    "<id материала>": {
      "cover": true,
      "ach": [{ "id": "…", "icon": "🔑", "name": "…", "hint": "…", "secret": false,
                "when": [["page", ">=", 45]] }],
      "words": { "<id награды>": "текст, который показывается при получении" },
      "facts": [{ "t": "заголовок", "x": "текст", "more": ["куда копнуть"], "page": 45 }]
    }
  }
}
```

Условия наград — данные, а не код. Метрика, оператор и значение: `[["pct", ">=", 100], ["days", ">=", 20]]` — все условия в списке объединяются по И. Операторы: `>=`, `>`, `<=`, `<`, `==`, `is` (для флагов), `has` (для наборов). Доступные метрики зависят от вида материала: `pct`, `page`, `days`, `streak`, `maxJump`, `notes`, `bars`, `pctR`, `pctL`, `done`, `lessons`, `minutes`, `weekend`, `reread`, `comeback`.

Обложки — отдельные файлы `cover-<id>.txt` с data URI, чтобы ни один файл гиста не разрастался.

## Экраны

- **◉ Главная** — лента обложек, кольцо прогресса, прогноз «в таком темпе примерно к…», кнопка отметки. Фон перекрашивается под обложку активного материала: оттенок берётся из самой картинки.
- **▤ Прогресс** — неделя или месяц: кольцо цели, метрики, график, общий календарь.
- **✎ Мысли** — лента записей с обложкой материала, лайками, фильтром любимых и кубиком «одна наугад».
- **✦ Достижения** — материалы с процентом, внутри две вкладки: награды и карточки знаний. Плюс полка прочитанного.
- **Мысль дня** — первый заход за день показывает одну из записей, без повторов внутри круга.

## Сохранность

- Данные всегда локальны, гист — копия. Слияние по времени правки, удаления помечаются флагом.
- Раз в неделю снимок всех данных уходит в отдельный гист-архив: файл на месяц, последние двенадцать.
- Резервная копия в файл и восстановление из него — в настройках.

## Локальный запуск

```bash
python3 serve.py 8473
```

Версию поднимать в трёх местах: `APP_VERSION` в `app.js`, `version.json`, `CACHE` в `sw.js`.
