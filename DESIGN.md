# Кэйко: визуальный контекст

Кэйко — личное приложение занятий на телефоне. Основной язык — русский;
稽古 в логотипе не означает японскую локализацию. Минимальная ширина — 320 CSS px.

## Источник оформления

Канонические токены находятся в `index.html`, в `:root` и существующих темах.
Фон — `--bg`, основной текст — `--ink`, подписи — `--muted`, поверхности —
`--card` / `--glass-2`, границы — `--line`, акцент и фокус — `--gold`.
Использовать эти переменные напрямую; новых независимых палитр не создавать.
Шрифт — существующий ui-rounded / SF Pro Rounded / system-ui. Обложки целиком,
с исходными пропорциями: object-fit: contain. Подписи не обрезают важные данные.

## Мой путь

Стабильный маршрут нижней панели - `progress`, подпись - «Мой путь».
Сверху компактные недельные цели: три тонкие цветные полосы с текущим объёмом
и целью для чтения, пианино и рисования. Выполненные цели отмечены галочкой.
Используется существующий расчёт недельных целей, фиксированные цели профиля
имеют приоритет. Суммы страниц, минут и занятий не складываются в одну величину.
Крупных колец, календаря, переключателя «Материалы / Занятия» и помощи здесь нет.
Старое сохранённое `pathView:activity` не меняет новый экран.

Ниже - история материалов от последней активности к старым, сгруппированная
по месяцам, с тонкой вертикальной линией. Карточка содержит обложку, название,
состояние, последний реальный день занятия и прогресс из существующих расчётов.
Даты начала берутся из первой не удалённой записи или явно сохранённого startedAt,
даты завершения - из doneAt / завершённого архива. Дата добавления материала
не выдаётся за начало занятия. Неизвестные даты не придумываются.
У свободного рисунка нет выдуманного процента. Материалы без истории остаются
в библиотеке, а в ленте появятся после первого занятия. Архивные карточки
сохраняются без дублей. Старые outwardActions продолжают безопасно храниться
и синхронизироваться, но из интерфейса история помощи скрыта.

## Данные и проверка

Источники — существующие отметки профиля. Просмотр истории ничего не записывает.
Архив сохраняет историю, удалённые отметки исключаются. Чтение использует
общую функцию pagesRead: повторное покрытие страниц не увеличивает счётчик,
книги без страниц не входят. Рисунок не включает просмотр видеоуроков.
Проверка: node --check app.js, node tools/test.js; браузер на 320 px,
смена недели, нулевая цель, достижение и превышение.

## Маршруты книги

В карте рядом с «Места» появляется «Маршруты», только если материал содержит
`journeys`. Компактные селекты участника и поездки, карта, нумерованная лента
остановок и карточка эпизода. Существующие токены, 44 px цели нажатия и ширина
320 px сохраняются. Карточка показывает главу, пересказ и раскрываемый фрагмент.
Открываются только остановки полностью прочитанных глав.

Если в приватном материале задан `yandex.key`, используется живая Яндекс.Карта
2.1 с масштабированием, перемещением, остановками и схематическими линиями.
Подпись «Схема перемещений» обязательна: соединения не являются GPS-треком
или восстановленной дорогой. При недоступности API остаётся сохранённая схема
с сообщением и повторной попыткой. Атрибуция картографического сервиса видна.
У приблизительного эпизода — пояснение и полупрозрачная область привязки;
если место не установлено, линии к нему и от него не рисуются.

Уточнение маршрутов: у участника один непрерывный список эпизодов в порядке
глав книги. Поездки остаются внутренней группировкой источника, но не отдельным
выбором пользователя. Селект «Глава» перемещает к первой остановке главы;
стрелки идут по всему списку. Между поездками и при неизвестной геопривязке
линий нет. Маршрутные точки фиолетовые, обычные упоминания — золотые.
На живой карте точки разных регионов доступны вместе без выбора подложки.
Последняя вкладка, глава, участник и остановка сохраняются на устройстве
отдельно для каждой книги. Явный переход к месту/главе важнее сохранённого.
Карточки мест дают краткий контекст из книги, а не общую энциклопедическую
справку; страны и слишком общие регионы для «Сов во льдах» убраны.

## Упрощение маршрута · 25 октября 2026

Для «Сов во льдах» приватная разметка `routeHidden` скрывает сомнительные
промежуточные эпизоды, сохраняя исходный текст и географический аудит.
`routeLabel` задаёт имя в ленте и на карте, `routeContext` - короткий пересказ
с датой без повторных строк. Соседние повторные остановки внутри поездки
сведены в одну карточку; возвраты после других мест остаются. Сохраняется id
исходной остановки, а не только индекс, чтобы сокращение не сбивало выбор.

В карточке остаются имя, краткий контекст и внешние ссылки. Погода,
температурные оценки, расстояния, цитата и «Почему здесь» в ней не показываются.
Кнопка «Панорамы» открывает слой Яндекс.Карт. `panorama.locate` ищет наземную
и воздушную съёмку; подтверждённая панорама в пределах 5 км получает отдельную
ссылку с расстоянием. Пустой ответ API не приравнивается к отсутствию всех
пользовательских панорам на сайте. Результаты кэшируются в памяти; ошибки
не кэшируются, устаревший ответ не меняет карточку другой остановки.

Навигация маршрута - один переключатель главы во всю ширину. Путь Джонатана
выбран без отдельного селекта участника. Лента имён прокручивается горизонтально
без перекрывающих её боковых стрелок.

## Финальная чистка истории и заметок · 25 октября 2026

У «Моего пути» нет отдельного заголовка и верхнего отступа: сразу начинаются
компактные цели недели. Длительность завершённого материала округляется
до дней, недель, месяцев или лет по календарю между началом и завершением.
Она не выдаётся за активное время занятий. Обложки из каталога подставляются
в placeholder на месте через coverPaint, без повторного входа и сброса скролла.

«Заметки» показывают только personalNotes: без diary, event и старых ev:-id.
Те же правила действуют для случайной заметки и счётчика избранного. Фильтр
не удаляет события из данных и не меняет историю занятий в «Моём пути».

## Статусы и скрытие в истории

Завершённые материалы имеют зелёный круг с галочкой, зелёный статус и шкалу.
Текущие - круг с указателем продолжения и тёплый акцент статуса. Иконка
и её обводка находятся внутри левого края скроллера (проверено на 320 px).
Список `__path__.historyHidden[profileId]` в приватном каталоге скрывает
выбранные карточки только в этой истории; сами материалы, занятия, архив
и недельные цели от него не меняются. Настройка относится к одному профилю.
